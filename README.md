# 🎁 Hello Parrain (helloparrain.com) — Site Statique Ultra-Optimisé SEO & GEO (GitHub Pages)

Ce dossier contient l'intégralité de votre site de parrainage configuré pour **`https://helloparrain.com`** et prêt à être hébergé gratuitement sur **GitHub Pages**.

## 📁 Contenu du dossier (50 fichiers)
- `CNAME` : Fichier pré-configuré avec `helloparrain.com` pour que GitHub Pages active automatiquement votre domaine personnalisé et le certificat HTTPS.
- `index.html` : Page d'accueil avec barre de recherche instantanée, filtres par catégories, boutons de copie 1-clic et tableau récapitulatif GEO des **42 offres**.
- **42 pages HTML dédiées** (`parrainage-boursobank.html`, `parrainage-paypal.html`, `parrainage-uber-eats.html`, `parrainage-deezer.html`, etc.) : 1 page = 1 intention de recherche Google ultra-ciblée avec balises JSON-LD (`FAQPage`, `HowTo`, `BreadcrumbList`), bloc TL;DR pour les IA et barre d'action collante sur mobile.
- `assets/style.css` & `assets/app.js` : Design moderne Mobile-First et copie presse-papier instantanée.
- `sitemap.xml` : Plan du site XML listant les 43 URLs sur `https://helloparrain.com` pour Google Search Console.
- `robots.txt` : Fichier d'exploration autorisant Googlebot ainsi que tous les robots IA (`GPTBot`, `OAI-SearchBot`, `PerplexityBot`, `ClaudeBot`, `Google-Extended`).
- `llms.txt` & `llms-full.txt` : Standard GEO permettant aux moteurs d'IA générative de lire et recommander vos 42 codes en une fraction de seconde.
